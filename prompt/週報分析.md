# 週報分析

> **用途**：讓 Claude CLI 分析每週自動產生的流量報告，提出數據驅動的優化建議。
>
> **使用方式**：在專案目錄執行 Claude CLI，輸入：
> ```
> 請參照 prompt/週報分析.md 分析最新週報
> ```

---

## 分析流程

### 1. 讀取最新週報

```bash
# 自動找出最新週報
ls -t reports/weekly-*.md | head -1
```

讀取 `reports/` 目錄中最新的週報檔案。

### 2. 分析維度

#### 2.1 流量趨勢
- 瀏覽量變化（與前週比較，如有歷史數據）
- 獨立訪客數
- Clone 數（開發者興趣指標）

#### 2.2 熱門頁面分析
- 哪些語言版本最受歡迎？
- 是否有意外的熱門頁面？
- 流量集中度如何？

#### 2.3 流量來源分析
- 主要來源（搜尋引擎、社群、直接流量）
- 是否有新的流量來源？
- 哪些來源轉換效果好？

#### 2.4 技術健檢結果
- Lighthouse 各項分數
- Core Web Vitals 狀態
- 安全性檢查結果

### 3. 產出優化建議

根據分析結果，產出具體、可執行的優化建議，按優先級分類：

| 優先級 | 定義 | 行動時機 |
|--------|------|----------|
| **P0** | 嚴重問題，影響用戶體驗或 SEO | 立即處理 |
| **P1** | 重要改進，有明確效益 | 本週處理 |
| **P2** | 優化項目，錦上添花 | 有空處理 |

## 常見優化建議參考

### 流量相關
- 某語言版本流量異常高 → 優先優化該版本的用戶體驗
- 流量集中在單一來源 → 拓展其他流量渠道
- 某頁面跳出率高 → 檢查內容是否符合用戶預期

### 技術相關
- Performance < 90 → 檢查圖片優化、JS 載入
- Accessibility < 90 → 檢查 ARIA labels、對比度
- SEO < 90 → 檢查 meta 標籤、結構化資料

### 內容相關
- 新流量來源 → 分析該來源用戶需求，考慮調整內容
- 特定語言流量上升 → 優化該語言的 SEO
