    Vuko 是什麼？

    Vuko 是一款免費、開源的雙耳拍頻（binaural beats）網頁應用，直接在瀏覽器中運作——無需安裝、不必註冊、沒有廣告。戴上耳機，選擇你想要的狀態，Vuko 就會即時產生精確的雙音頻率，溫和地引導你的大腦進入專注、冥想、放鬆或深層睡眠。

    Vuko 與眾不同之處，在於它不只是播放一段固定的音軌。若你允許使用麥克風，Vuko 會即時聆聽你的呼吸，並依你當下的真實狀態調整拍頻——在你的身體與聲音之間形成一個閉環回饋。我們遍尋不著另一個能在瀏覽器中同時結合「雙耳拍頻」與「即時呼吸監測」的工具，而這正是 Vuko 所填補的空缺。

    會跟著呼吸即時調整的雙耳拍頻

    多數雙耳拍頻 App 只是播放固定音軌，期望它剛好符合你的感受。Vuko 不一樣：它是一個「呼吸自適應」的雙耳拍頻產生器。開啟麥克風後，Vuko 會聆聽你的呼吸節奏，並持續把拍頻重新調校到你當下的真實狀態——當呼吸趨於平緩，拍頻也隨之放慢，讓你比固定音軌更快進入專注、平靜或睡眠。

    這個與呼吸同步的回饋迴圈完全在你的瀏覽器中運作。不錄音、不上傳，也不需要任何穿戴裝置或額外硬體——只要一副耳機，以及（可選的）裝置麥克風。如果你曾搜尋「會跟著呼吸調整的雙耳拍頻」「與呼吸同步的冥想聲音」或「自適應腦波產生器」，那正是 Vuko 想成為的樣子。

    Vuko 如何運作

    Vuko 結合了兩個通常分屬不同 App 的系統：一個雙耳拍頻引擎，以及一個即時呼吸監測器，兩者在你聆聽時彼此對話。

    1. 雙耳拍頻引擎

    當你的左右耳分別聽到略微不同的頻率——例如 200 Hz 與 210 Hz——大腦會在兩者的差值處感知到第三個「拍頻」（10 Hz）。這個幻覺般的拍頻能引導腦波趨近該節奏，這個過程常被稱為「腦波同步」（entrainment）。由於效果取決於左右耳各自聽到專屬聲道，因此必須使用立體聲耳機。Vuko 以 Web Audio API 即時產生這些音調，聲音是在你的裝置上生成，而非串流而來。

    2. 即時呼吸監測

    在你同意後，Vuko 會透過麥克風偵測你輕柔的呼吸聲，量測你的呼吸速率，並依你此刻的狀態調整拍頻——當你放鬆時放慢節奏，引導你更深入地接近目標狀態。所有音訊都完全在你的裝置上分析，絕不離開你的瀏覽器。若你不願意，也可以略過麥克風，單純選擇一種預設模式。

    六種引導狀態

    選擇你想要的狀態，Vuko 便會把拍頻調校到對應的腦波頻段。每個預設模式都對應一個廣為人知的頻率範圍：

    以隱私為本，永久免費

    Vuko 沒有任何儲存你資料的後端伺服器。所有聲音生成與呼吸分析都在你的瀏覽器本機進行，因此你的麥克風音訊絕不會被上傳、錄製或分享。沒有任何東西需要註冊，也不必付費。

    整個專案在 GitHub 上開源——你可以親自閱讀它的運作方式、驗證隱私承諾，並參與貢獻。它今天免費可用，而且立意如此長久。

    如何使用 Vuko

    1. 戴上立體聲耳機——唯有左右耳各自聽到專屬聲道，雙耳拍頻才會生效。
    2. 選擇一種模式，例如專注、冥想或睡眠，或從內建音庫加入背景音樂。
    3. 可選擇允許麥克風存取，讓 Vuko 監測你的呼吸並為你調整拍頻。
    4. 按下開始，自然呼吸，讓聲音帶你遇見更好的自己。

    常見問題

    什麼是雙耳拍頻？
    雙耳拍頻是當左右耳聽到略微不同頻率的聲音時，大腦會產生第三個「拍頻」。例如左耳 200Hz、右耳 210Hz，大腦會感知到 10Hz 的拍頻，這可以幫助引導腦波進入特定狀態。
    哪一款雙耳拍頻 App 會跟著呼吸調整？
    Vuko 是一款免費、開源的網頁 App，會即時依你的呼吸調整雙耳拍頻。在你同意後，它會透過裝置麥克風偵測你的呼吸節奏，並持續把拍頻重新調校到你當下的狀態——目前沒有其他瀏覽器上的雙耳拍頻工具像這樣結合拍頻與即時呼吸監測。所有運算都在本機進行，不錄音、不上傳。
    使用呼吸自適應拍頻需要穿戴裝置或智慧手錶嗎？
    不需要。Vuko 只需要一副立體聲耳機，以及（可選的）裝置內建麥克風。不必任何穿戴裝置、胸帶或額外硬體——麥克風會偵測你的呼吸，音訊完全在你的瀏覽器中分析後即丟棄。
    為什麼一定要用耳機？
    雙耳拍頻的原理是讓左右耳分別聽到不同頻率，只有使用耳機才能確保左右聲道分離，讓大腦正確產生拍頻效果。
    呼吸監測是如何運作的？
    系統透過麥克風偵測您的呼吸聲，分析呼吸節奏，並根據您的狀態自動調整拍頻，幫助您更快進入目標狀態。所有音訊僅在本機處理，不會上傳。
    這個工具真的免費嗎？
    是的，Vuko 完全免費且開源。沒有隱藏費用、沒有訂閱、沒有廣告。您可以在 GitHub 上查看完整程式碼。
    我的資料安全嗎？
    絕對安全。所有音訊處理都在您的瀏覽器中進行，我們不會收集、儲存或傳輸任何音訊資料。這是一個純前端應用，沒有後端伺服器。
