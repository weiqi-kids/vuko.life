    Vuko 是甚麼？

    Vuko 是一款免費、開源的雙耳拍頻（binaural beats）網頁應用程式，直接在瀏覽器中運作——毋須安裝、毋須註冊、沒有廣告。戴上耳機，揀選你想要的狀態，Vuko 就會即時產生精準的雙音頻率，溫和地引導你的大腦進入專注、冥想、放鬆或深層睡眠。

    Vuko 與別不同之處，在於它不只是播放一段固定的音軌。若你允許使用麥克風，Vuko 會即時聆聽你的呼吸，並按你當下的真實狀態調整拍頻——在你的身體與聲音之間形成一個閉環回饋。我們遍尋不獲另一個能在瀏覽器中同時結合「雙耳拍頻」與「即時呼吸監測」的工具，而這正是 Vuko 所填補的空缺。

    Vuko 如何運作

    Vuko 結合了兩個通常分屬不同 App 的系統：一個雙耳拍頻引擎，以及一個即時呼吸監測器，兩者在你聆聽時彼此對話。

    1. 雙耳拍頻引擎

    當你的左右耳分別聽到略有不同的頻率——例如 200 Hz 與 210 Hz——大腦會在兩者的差值處感知到第三個「拍頻」（10 Hz）。這個彷彿幻覺般的拍頻能引導腦波趨近該節奏，這個過程常被稱為「腦波同步」（entrainment）。由於效果取決於左右耳各自聽到專屬聲道，因此必須使用立體聲耳機。Vuko 以 Web Audio API 即時產生這些音調，聲音是在你的裝置上生成，而非串流而來。

    2. 即時呼吸監測

    在你同意後，Vuko 會透過麥克風偵測你輕柔的呼吸聲，量度你的呼吸速率，並按你此刻的狀態調整拍頻——當你放鬆時放慢節奏，引導你更深入地接近目標狀態。所有音訊都完全在你的裝置上分析，絕不離開你的瀏覽器。若你不願意，亦可略過麥克風，單純揀選一種預設模式。

    六種引導狀態

    揀選你想要的狀態，Vuko 便會把拍頻調校到對應的腦波頻段。每個預設模式都對應一個廣為人知的頻率範圍：

    模式 拍頻 腦波頻段 最適合

    冥想 7 Hz Theta 深層放鬆與正念

    以私隱為本，永久免費

    Vuko 沒有任何儲存你資料的後端伺服器。所有聲音生成與呼吸分析都在你的瀏覽器本機進行，因此你的麥克風音訊絕不會被上載、錄製或分享。沒有任何東西需要註冊，亦毋須付費。

    整個專案在 GitHub 上開源——你可以親自閱讀它的運作方式、驗證私隱承諾，並參與貢獻。它今天免費可用，而且立意如此長久。

    如何使用 Vuko

    1. 戴上立體聲耳機——唯有左右耳各自聽到專屬聲道，雙耳拍頻才會生效。
    2. 揀選一種模式，例如專注、冥想或睡眠，或從內置音庫加入背景音樂。
    3. 可選擇允許麥克風存取，讓 Vuko 監測你的呼吸並為你調整拍頻。
    4. 按下開始，自然呼吸，讓聲音帶你遇見更好的自己。

    常見問題

    什麼是雙耳拍頻？
    雙耳拍頻是當左右耳聽到略微不同頻率的聲音時，大腦會產生第三個「拍頻」。例如左耳 200Hz、右耳 210Hz，大腦會感知到 10Hz 的拍頻，這可以幫助引導腦波進入特定狀態。
    為什麼一定要用耳機？
    雙耳拍頻的原理係讓左右耳分別聽到唔同頻率，只有使用耳機先可以確保左右聲道分離，令大腦正確產生拍頻效果。
    呼吸監測係點樣運作嘅？
    系統透過咪高峰偵測您嘅呼吸聲，分析呼吸節奏，並根據您嘅狀態自動調整拍頻，幫助您更快進入目標狀態。所有音訊僅喺本機處理，唔會上傳。
    呢個工具真係免費嘅嗎？
    係嘅，Vuko 完全免費且開源。冇隱藏費用、冇訂閱、冇廣告。您可以喺 GitHub 上查看完整程式碼。
    我嘅資料安全嗎？
    絕對安全。所有音訊處理都喺您嘅瀏覽器中進行，我哋唔會收集、儲存或傳輸任何音訊資料。呢係一個純前端應用，冇後端伺服器。
