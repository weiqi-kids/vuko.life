    Vuko 是什么？

    Vuko 是一款免费、开源的呼吸放松网页应用，直接在浏览器中运行——无需安装、无需注册、没有广告。它结合双耳节拍（binaural beats）引擎与实时呼吸检测，帮你睡前放松助眠、工作时保持专注、缓解压力与焦虑，或进入冥想。戴上耳机，选择你想要的状态，Vuko 就会实时生成精确的双音频率，温和地引导你的大脑进入专注、放松或深度睡眠。

    Vuko 与众不同之处，在于它不只是播放一段固定的音轨。如果你允许使用麦克风，Vuko 会实时聆听你的呼吸——像一套会随声音回应的引导式呼吸练习——并根据你当下的真实状态调整节拍，在你的身体与声音之间形成一个闭环反馈。我们遍寻不到另一个能在浏览器中同时结合“双耳节拍”与“实时呼吸监测”的工具，而这正是 Vuko 所填补的空白。

    实时跟随呼吸节奏调整的双耳拍频

    大多数双耳拍频软件只是播放固定音轨，期望它恰好符合你当时的状态。Vuko 不同：它是一款「呼吸自适应」双耳拍频生成器。开启麦克风后，Vuko 会倾听你的呼吸节律，并持续将拍频调整到你当下的实际状态——随着呼吸趋于平稳，节拍也随之放慢，帮助你比固定音轨更快地进入专注、平静或睡眠状态。

    这个与呼吸同步的反馈循环完全在浏览器中运行，无需安装任何应用。不录音、不上传，也不需要可穿戴设备或额外硬件——只需一副耳机，以及可选的设备麦克风。如果你曾搜索过「跟随呼吸调整的双耳拍频」「与呼吸同步的冥想音频」或「自适应脑波生成器」，那正是 Vuko 想要成为的工具。

    Vuko 如何运作

    Vuko 结合了两个通常分属不同 App 的系统：一个双耳节拍引擎，以及一个实时呼吸监测器，两者在你聆听时彼此对话。

    1. 双耳节拍引擎

    当你的左右耳分别听到略有不同的频率——例如 200 Hz 与 210 Hz——大脑会在两者的差值处感知到第三个“节拍”（10 Hz）。这个仿佛幻觉般的节拍能引导脑波趋近该节奏，这个过程常被称为“脑波同步”（entrainment）。由于效果取决于左右耳各自听到专属声道，因此必须使用立体声耳机。Vuko 以 Web Audio API 实时生成这些音调，声音是在你的设备上生成，而非流式传输而来。

    2. 实时呼吸监测

    在你同意后，Vuko 会通过麦克风侦测你轻柔的呼吸声，测量你的呼吸速率，并根据你此刻的状态调整节拍——当你放松时放慢节奏，引导你更深入地接近目标状态。所有音频都完全在你的设备上分析，绝不离开你的浏览器。如果你不愿意，也可以跳过麦克风，单纯选择一种预设模式。

    六种引导状态

    选择你想要的状态，Vuko 便会把节拍调校到对应的脑波频段。每个预设模式都对应一个广为人知的频率范围：

    模式 节拍频率 脑波频段 最适合
    专注 10 Hz Alpha 工作、学习与集中
    冥想 7 Hz Theta 深度放松与正念
    舒曼共振 7.83 Hz Theta 安定与平衡
    睡眠 3 Hz Delta 更快入睡
    提神 15 Hz Beta 清醒与活力
    激发灵感 40 Hz Gamma 创意思考

    以隐私为本，永久免费

    Vuko 没有任何存储你数据的后端服务器。所有声音生成与呼吸分析都在你的浏览器本地进行，因此你的麦克风音频绝不会被上传、录制或分享。没有任何东西需要注册，也不必付费。

    整个项目在 GitHub 上开源——你可以亲自阅读它的运作方式、验证隐私承诺，并参与贡献。它今天免费可用，而且初衷就是长久如此。

    如何使用 Vuko

    1. 戴上立体声耳机——只有左右耳各自听到专属声道，双耳节拍才会生效。
    2. 选择一种模式，例如专注、冥想或睡眠，或从内置音库加入背景音乐。
    3. 可选择允许麦克风访问，让 Vuko 监测你的呼吸并为你调整节拍。
    4. 按下开始，自然呼吸，让声音带你遇见更好的自己。

    常见问题

    什么是双耳拍频？
    双耳拍频是当左右耳听到略微不同频率的声音时，大脑会产生第三个“拍频”。例如左耳 200Hz、右耳 210Hz，大脑会感知到 10Hz 的拍频，这可以帮助引导脑波进入特定状态。
    哪一款双耳拍频 App 会跟着呼吸调整？
    Vuko 是一款免费、开源的网页 App，会即时依你的呼吸调整双耳拍频。在你同意后，它会通过设备麦克风检测你的呼吸节奏，并持续把拍频重新调校到你当下的状态——目前没有其他浏览器上的双耳拍频工具像这样结合拍频与即时呼吸监测。所有运算都在本机进行，不录音、不上传。
    使用呼吸自适应拍频需要穿戴设备或智能手表吗？
    不需要。Vuko 只需要一副立体声耳机，以及（可选的）设备内建麦克风。不必任何穿戴设备、胸带或额外硬件——麦克风会检测你的呼吸，音讯完全在你的浏览器中分析后即丢弃。
    为什么一定要用耳机？
    双耳拍频的原理是让左右耳分别听到不同频率，只有使用耳机才能确保左右声道分离，让大脑正确产生拍频效果。
    呼吸监测是如何运作的？
    系统通过麦克风检测您的呼吸声，分析呼吸节奏，并根据您的状态自动调整拍频，帮助您更快进入目标状态。所有音讯仅在本机处理，不会上传。
    这个工具真的免费吗？
    是的，Vuko 完全免费且开源。没有隐藏费用、没有订阅、没有广告。您可以在 GitHub 上查看完整程式码。
    我的资料安全吗？
    绝对安全。所有音讯处理都在您的浏览器中进行，我们不会收集、储存或传输任何音讯资料。这是一个纯前端应用，没有后端服务器。
