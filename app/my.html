    Vuko ဆိုတာ ဘာလဲ။

    Vuko သည် သင့်ဘရောက်ဇာထဲတွင် တိုက်ရိုက်အသုံးပြုနိုင်သော အခမဲ့၊ open-source binaural beats ဝက်ဘ်အက်ပ်တစ်ခုဖြစ်ပြီး — ထည့်သွင်းစရာမလို၊ အကောင့်ဖွင့်စရာမလို၊ ကြော်ငြာမပါပါ။ နားကြပ်တပ်ဆင်ပြီး သင်ခံစားလိုသည့်အခြေအနေကို ရွေးချယ်လိုက်ရုံဖြင့် Vuko က တိကျသော အသံနှစ်လှိုင်းကြိမ်နှုန်းများကို ချက်ချင်းထုတ်ပေးကာ သင့်ဦးနှောက်ကို အာရုံစူးစိုက်မှု၊ တရားထိုင်ခြင်း၊ အပန်းဖြေခြင်း သို့မဟုတ် အိပ်စက်အနားယူခြင်းဆီသို့ နူးညံ့စွာ ဦးတည်ပေးပါသည်။

    Vuko ၏ ထူးခြားချက်မှာ ပုံသေသီချင်းတစ်ပုဒ်ကိုသာ ဖွင့်ပေးခြင်းမဟုတ်ပါ။ မိုက်ခရိုဖုန်းအသုံးပြုခွင့်ပေးပါက Vuko က သင့်အသက်ရှူသံကို ချက်ချင်းနားထောင်ပြီး သင့်လက်ရှိအခြေအနေအတိုင်း အသံလှိုင်းများကို ချိန်ညှိပေးပါသည် — သင့်ခန္ဓာကိုယ်နှင့် အသံကြားတွင် ပိတ်ထားသော တုံ့ပြန်မှုစက်ဝန်းတစ်ခု ဖြစ်ပေါ်လာစေပါသည်။ binaural beats နှင့် တိုက်ရိုက်အသက်ရှူမှုစောင့်ကြည့်ခြင်းကို ဘရောက်ဇာထဲတွင် ပေါင်းစပ်ထားသည့် အခြားကိရိယာတစ်ခုမျှ ကျွန်ုပ်တို့ရှာမတွေ့ခဲ့ပါ — ၎င်းသည်ပင် Vuko ဖြည့်ဆည်းပေးနေသော ကွက်လပ်ဖြစ်ပါသည်။

    Vuko အလုပ်လုပ်ပုံ

    Vuko သည် ပုံမှန်အားဖြင့် သီးခြားအက်ပ်များတွင် ရှိနေတတ်သော စနစ်နှစ်ခုကို ပေါင်းစပ်ထားပါသည် — binaural beats စက်ယန္တရားတစ်ခုနှင့် တိုက်ရိုက်အသက်ရှူမှု စောင့်ကြည့်ကိရိယာတစ်ခုဖြစ်ပြီး သင်နားထောင်နေစဉ် ၎င်းတို့နှစ်ခု အချင်းချင်း ဆက်သွယ်ပြောဆိုနေကြပါသည်။

    ၁။ Binaural beats စက်ယန္တရား

    သင့်ဘယ်နားနှင့် ညာနားက အနည်းငယ်ကွဲပြားသော ကြိမ်နှုန်းနှစ်ခု — ဥပမာ 200 Hz နှင့် 210 Hz — ကို ကြားသောအခါ ဦးနှောက်က ၎င်းတို့၏ ကွာခြားချက်တွင် တတိယ "လှိုင်း" (10 Hz) ကို ခံစားမိပါသည်။ ဤထင်ယောင်ထင်မှားလှိုင်းသည် သင့်ဦးနှောက်လှိုင်းများကို ထိုစည်းချက်အနီးသို့ တည်ငြိမ်စေနိုင်ပြီး ၎င်းကို entrainment ဟု မကြာခဏ ခေါ်ဆိုကြပါသည်။ အကျိုးသက်ရောက်မှုသည် နားတစ်ဖက်စီက ၎င်း၏သီးခြားလမ်းကြောင်းကို ကြားရခြင်းအပေါ် မူတည်သောကြောင့် stereo နားကြပ် မဖြစ်မနေ လိုအပ်ပါသည်။ Vuko က ဤအသံများကို Web Audio API ဖြင့် တိုက်ရိုက်ထုတ်လုပ်သောကြောင့် အသံသည် stream ဖြင့်ရရှိခြင်းမဟုတ်ဘဲ သင့်ကိရိယာပေါ်တွင် ဖန်တီးပေးခြင်းဖြစ်ပါသည်။

    ၂။ တိုက်ရိုက်အသက်ရှူမှု စောင့်ကြည့်ခြင်း

    သင်ခွင့်ပြုပါက Vuko က မိုက်ခရိုဖုန်းကို အသုံးပြု၍ သင့်နူးညံ့သော အသက်ရှူသံကို ရှာဖွေသိရှိကာ သင့်အသက်ရှူနှုန်းကို တိုင်းတာပြီး သင့်လက်ရှိအခြေအနေနှင့် ကိုက်ညီအောင် အသံလှိုင်းကြိမ်နှုန်းကို ချိန်ညှိပေးပါသည် — သင်အပန်းဖြေလာသည်နှင့်အမျှ စည်းချက်ကို နှေးကွေးစေကာ ရည်မှန်းချက်အခြေအနေဆီသို့ ပိုမိုနက်ရှိုင်းစွာ ဦးတည်စေပါသည်။ အသံအားလုံးကို သင့်ကိရိယာပေါ်တွင်သာ ပြည့်စုံစွာ ခွဲခြမ်းစိတ်ဖြာပြီး သင့်ဘရောက်ဇာမှ ဘယ်သောအခါမျှ ထွက်မသွားပါ။ အလိုရှိပါက မိုက်ခရိုဖုန်းကို ကျော်လွှား၍ ကြိုတင်သတ်မှတ်ထားသော mode တစ်ခုကိုသာ ရွေးချယ်နိုင်ပါသည်။

    လမ်းညွှန်ပေးသော အခြေအနေ ခြောက်မျိုး

    သင်အလိုရှိသော အခြေအနေကို ရွေးချယ်လိုက်ပါက Vuko က အသံလှိုင်းကြိမ်နှုန်းကို သက်ဆိုင်ရာ ဦးနှောက်လှိုင်းအပိုင်းအခြားနှင့် ကိုက်ညီအောင် ချိန်ညှိပေးပါသည်။ ကြိုတင်သတ်မှတ် mode တစ်ခုစီသည် လူသိများသော ကြိမ်နှုန်းအပိုင်းအခြားတစ်ခုကို ဦးတည်ပါသည် —

    Mode လှိုင်းကြိမ်နှုန်း ဦးနှောက်လှိုင်းအပိုင်း အသင့်တော်ဆုံး
    အာရုံစူးစိုက် 10 Hz Alpha အလုပ်၊ စာသင်ယူခြင်းနှင့် စိတ်စူးစိုက်မှု
    တရားထိုင် 7 Hz Theta နက်ရှိုင်းသော အပန်းဖြေမှုနှင့် သတိပဋ္ဌာန်
    Schumann လှိုင်းတုန်ခါမှု 7.83 Hz Theta တည်ငြိမ်မှုနှင့် ဟန်ချက်ညီမှု
    အိပ်စက်ခြင်း 3 Hz Delta ပိုမြန်စွာ အိပ်ပျော်စေခြင်း
    လန်းဆန်းမှု 15 Hz Beta နိုးကြားမှုနှင့် စွမ်းအင်
    စိတ်ကူးစိတ်သန်းနှိုးဆွ 40 Hz Gamma တီထွင်ဖန်တီးသော အတွေးအခေါ်

    ကိုယ်ရေးကိုယ်တာအတွက် ဒီဇိုင်းရေးဆွဲထား၊ ထာဝစဉ်အခမဲ့

    Vuko တွင် သင့်ဒေတာကို သိမ်းဆည်းသည့် နောက်ကွယ်ဆာဗာ မရှိပါ။ အသံထုတ်လုပ်ခြင်းနှင့် အသက်ရှူမှုခွဲခြမ်းစိတ်ဖြာခြင်း အားလုံးကို သင့်ဘရောက်ဇာထဲ၌သာ ဒေသတွင်း ဆောင်ရွက်သောကြောင့် သင့်မိုက်ခရိုဖုန်းအသံကို ဘယ်သောအခါမျှ အပ်လုဒ်လုပ်ခြင်း၊ မှတ်တမ်းတင်ခြင်း သို့မဟုတ် မျှဝေခြင်း မပြုလုပ်ပါ။ စာရင်းသွင်းစရာ ဘာမှမရှိသလို ပေးချေစရာလည်း ဘာမှမရှိပါ။

    စီမံကိန်းတစ်ခုလုံးသည် GitHub ပေါ်တွင် open source ဖြစ်ပါသည် — ၎င်းအလုပ်လုပ်ပုံကို သင်ကိုယ်တိုင် ဖတ်ရှုနိုင်ပြီး ကိုယ်ရေးကိုယ်တာကတိကဝတ်များကို စစ်ဆေးအတည်ပြုကာ ပါဝင်ကူညီနိုင်ပါသည်။ ၎င်းသည် ယနေ့အခမဲ့အသုံးပြုနိုင်ပြီး ထိုသို့ ဆက်လက်တည်ရှိနေစေရန် တည်ဆောက်ထားခြင်းဖြစ်ပါသည်။

    Vuko အသုံးပြုနည်း

    1. Stereo နားကြပ် တပ်ဆင်ပါ — နားတစ်ဖက်စီက ၎င်း၏သီးခြားလမ်းကြောင်းကို ကြားမှသာ binaural beats အလုပ်လုပ်ပါသည်။
    2. အာရုံစူးစိုက်၊ တရားထိုင် သို့မဟုတ် အိပ်စက်ခြင်း ကဲ့သို့သော mode တစ်ခုကို ရွေးချယ်ပါ၊ သို့မဟုတ် တပ်ဆင်ပါရှိသော သီချင်းစုစည်းမှုမှ နောက်ခံဂီတ ထည့်သွင်းပါ။
    3. Vuko က သင့်အသက်ရှူမှုကို စောင့်ကြည့်ပြီး သင့်အတွက် အသံလှိုင်းများ ချိန်ညှိနိုင်ရန် မိုက်ခရိုဖုန်းအသုံးပြုခွင့်ကို လိုအပ်ပါက ခွင့်ပြုပါ။
    4. Start ကိုနှိပ်ပါ၊ သဘာဝအတိုင်း အသက်ရှူပါ၊ အသံက သင့်ကို ပိုမိုကောင်းမွန်သော သင်ဆီသို့ ဦးတည်ပို့ဆောင်ပါစေ။

    မကြာခဏမေးလေ့ရှိသော မေးခွန်းများ

    နှစ်ဘက်နားကြပ်လှိုင်းဆိုသည်မှာ အဘယ်နည်း?
    နှစ်ဘက်နားကြပ်လှိုင်းဆိုသည်မှာ ဘယ်နားနှင့် ညာနားသည် အနည်းငယ်ကွဲပြားသော ကြိမ်နှုန်းရှိသော အသံကို ကြားရသောအခါ ဦးနှောက်သည် တတိယ "လှိုင်း" ကို ဖန်တီးသည်။ ဥပမာအားဖြင့် ဘယ်နား 200Hz၊ ညာနား 210Hz ဖြစ်ပါက ဦးနှောက်သည် 10Hz လှိုင်းကို ခံစားရမည်ဖြစ်ပြီး ဦးနှောက်လှိုင်းကို အထူးအခြေအနေသို့ ဦးတည်ရန် ကူညီပေးနိုင်သည်။
    ဘာကြောင့် နားကြပ်ကို အသုံးပြုရမည်နည်း?
    နှစ်ဖက်နားကြပ်အသံရိုက်နှုန်း၏ နိယာမသည် ဘယ်နားနှင့်ညာနားသို့ မတူညီသော ကြိမ်နှုန်းများကို ကြားရစေခြင်းဖြစ်ပြီး၊ နားကြပ်ကိုသာ အသုံးပြုရမည်ဖြစ်သည်။ ညာဘက်နှင့် ဘယ်ဘက်အသံလမ်းကြောင်းခွဲခြားမှုကို သေချာစေရန်နှင့် ဦးနှောက်မှ ရိုက်နှုန်းအကျိုးသက်ရောက်မှုကို မှန်ကန်စွာ ဖန်တီးစေရန်ဖြစ်သည်။
    အသက်ရှူခြင်းကို မည်သို့စစ်ဆေးသနည်း?
    စနစ်သည် မိုက်ခရိုဖုန်းမှ သင့်အသက်ရှူသံကို စစ်ဆေးပြီး အသက်ရှူလှိုင်းနှုန်းကို ခွဲခြမ်းစိတ်ဖြာကာ သင့်အခြေအနေအရ ရိုက်နှုန်းကို အလိုအလျောက် ချိန်ညှိပေးပြီး သင့်ကို ပစ်မှတ်ထားသော အခြေအနေသို့ ပိုမိုလျင်မြန်စွာ ရောက်ရှိစေရန် ကူညီပေးပါသည်။ အသံများအားလုံးကို ဒေသတွင်းတွင်သာ 처리ပြီး၊ အွန်လိုင်းသို့ မတင်ပို့ပါ။
    ဒီကိရိယာက အခမဲ့လား?
    ဟုတ်ပါတယ်၊ Vuko သည် အခမဲ့ဖြစ်ပြီး အရင်းအမြစ်ဖွင့်လှစ်ထားပါသည်။ ဖျောက်ထားသော ကုန်ကျစရိတ်များ၊ စာရင်းသွင်းခြင်းများ၊ ကြော်ငြာများ မရှိပါ။ GitHub တွင် အပြည့်အစုံသော ကုဒ်ကို ကြည့်ရှုနိုင်ပါသည်။
    ကျွန်ုပ်၏ဒေတာများ ဘေးကင်းလုံခြုံပါသလား?
    အပြည့်အဝ လုံခြုံပါသည်။ အသံများအားလုံးကို သင့်ဘရောက်ဇာတွင်သာ 처리ပြီး၊ ကျွန်ုပ်တို့သည် အသံဒေတာများကို စုဆောင်းခြင်း၊ သိမ်းဆည်းခြင်း သို့မဟုတ် ပို့ဆောင်ခြင်း မပြုပါ။ ၎င်းသည် pure frontend အက်ပ်ဖြစ်ပြီး၊ backend ဆာဗာ မရှိပါ။
