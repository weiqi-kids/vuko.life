# 品牌定位文件

## 1. 核心資訊

| 項目 | 內容 |
|------|------|
| **網站名稱** | Vuko - 智能呼吸節奏處理器 |
| **一句話描述** | 透過雙耳拍頻與即時呼吸監測，引導用戶進入冥想、睡眠、專注等狀態的免費 Web App |
| **核心價值主張** | 不需安裝 App、不需付費、不需註冊，打開瀏覽器就能使用的 AI 智能呼吸引導工具 |

## 2. 目標受眾

### 主要受眾 (Primary)
| 項目 | 描述 |
|------|------|
| **是誰** | 有冥想/睡眠/專注需求的現代人 |
| **目標/需求** | 想要透過聲音輔助進入放鬆、專注或睡眠狀態 |
| **痛點** | 冥想 App 太貴（Calm、Headspace）、功能太複雜、需要註冊 |
| **使用場景** | 睡前放鬆、工作時專注、冥想練習時 |

### 次要受眾 (Secondary)
| 項目 | 描述 |
|------|------|
| **是誰** | 身心靈練習者、呼吸練習者 |
| **目標/需求** | 需要呼吸引導工具輔助練習 |
| **痛點** | 現有工具無法即時監測呼吸並自動調整 |
| **使用場景** | 瑜珈課後、靜坐冥想時、呼吸訓練時 |

## 3. 差異化定位

| 項目 | 內容 |
|------|------|
| **與競品的差異** | 完全免費、開源、無需註冊、即開即用 |
| **獨特優勢** | AI 即時呼吸監測 + 自動調整拍頻（競品多為固定頻率） |
| **不做什麼** | 不做課程內容、不做社群功能、不做訂閱制 |
